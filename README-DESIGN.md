# DropZone UI refresh

This version keeps the existing DropZone functionality and refreshes only the front end.

### Visual changes
- Premium dark gaming UI with neon purple/cyan accents
- Stronger branding and hero section
- Glassy/polished cards, room list, chat, buttons and dialogs
- Responsive mobile layout
- Better empty states, room counter and live status
- Cleaner typography using Inter + Barlow Condensed

Replace `public/index.html`, `public/style.css`, and `public/app.js` in your existing repository with the versions in this package.
